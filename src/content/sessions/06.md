# Sesión 06 · Event Loop

**Objetivo:** poder trazar código síncrono, microtasks y tasks, y explicar qué hace `await`.

## Modelo mental (10 min)

Antes de resolver, escribe tres columnas: «pila síncrona», «cola de microtasks», «cola de tasks». Para cada fragmento anota en qué momento se agrega cada callback. El orden de una misma cola es el orden de encolado de los callbacks en estos ejemplos.

## Predice el orden exacto (35 min)

**6.1**
```js
console.log('start');
queueMicrotask(() => console.log('micro'));
console.log('end');
```

**6.2**
```js
console.log('one');
setTimeout(() => console.log('timer'), 0);
Promise.resolve().then(() => console.log('then'));
console.log('two');
```

**6.3**
```js
async function work() {
  console.log(1);
  await 0;
  console.log(3);
}
console.log(0);
work();
console.log(2);
```

**6.4**
```js
Promise.resolve().then(() => {
  console.log('A');
  queueMicrotask(() => console.log('C'));
});
Promise.resolve().then(() => console.log('B'));
console.log('D');
```

**6.5**
```js
setTimeout(() => {
  console.log('T');
  Promise.resolve().then(() => console.log('M'));
}, 0);
setTimeout(() => console.log('U'), 0);
```

**6.6**
```js
console.log('X');
Promise.resolve().then(() => {
  console.log('Y');
  return Promise.resolve();
}).then(() => console.log('Z'));
console.log('W');
```

**6.7**
```js
async function f() {
  await Promise.resolve();
  console.log('async');
}
Promise.resolve().then(() => console.log('promise'));
f();
console.log('sync');
```

**6.8**
```js
async function f() {
  console.log('a');
  await Promise.resolve();
  console.log('c');
}
console.log('x');
f();
queueMicrotask(() => console.log('d'));
console.log('b');
```

## Hazlo tú (10 min)

**6.9.** Diseña un ejemplo mínimo que imprima exactamente `uno`, `tres`, `dos` usando `console.log()` y una microtask.

**6.10.** En el ejemplo 6.8, explica por qué `a` ocurre antes de `b` y `c` después. No basta con decir «por ser async».

Dibuja el orden de colas de tu ejercicio más difícil y comprueba en el solucionario correspondiente (pendiente de incorporar).
