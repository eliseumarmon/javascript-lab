# Sesión 01 · Scope, hoisting y TDZ

**Objetivo:** distinguir `var`, `let` y `const`, bloque frente a función, hoisting y Temporal Dead Zone. Tiempo: 50 minutos.

## Calentamiento (10 min)

Sin consultar referencias, escribe en tres líneas: (a) ámbito de `var`, (b) ámbito de `let`, (c) qué ocurre si se lee una variable antes de inicializarla. No busques aún la respuesta.

## Predice antes de ejecutar (25 min)

Para cada ejercicio, escribe **salida exacta o tipo de error** y una frase con la causa. **Ejecuta cada bloque por separado**.

**1.1**
```js
console.log(score);
var score = 9;
```

**1.2**
```js
console.log(score);
let score = 9;
```

**1.3**
```js
function run() {
  if (true) {
    var total = 4;
  }
  return total;
}
console.log(run());
```

**1.4**
```js
function run() {
  if (true) {
    let total = 4;
  }
  return total;
}
console.log(run());
```

**1.5**
```js
let level = 2;
{
  let level = 8;
  console.log(level);
}
console.log(level);
```

**1.6**
```js
const user = { visits: 0 };
user.visits += 1;
console.log(user.visits);
```

**1.7**
```js
var mode = 'A';
{
  var mode = 'B';
}
console.log(mode);
```

**1.8**
```js
let status = 'outside';
{
  console.log(status);
  let status = 'inside';
}
```

## Programación breve (10 min)

**1.9.** Reescribe el siguiente código para que imprima `0`, `1`, `2` en ese orden, sin cambiar `setTimeout` y sin introducir funciones auxiliares:
```js
for (var index = 0; index < 3; index++) {
  setTimeout(() => console.log(index), 0);
}
```

**1.10.** Explica por qué esto **no** es válido y escribe una versión válida que impida reasignar `port`:
```js
const port;
port = 3000;
```

## Cierre (5 min)

Resume en voz alta: «`var` es de ámbito…, `let` y `const` son de ámbito…; TDZ significa…». Anota tus dudas. Después contrasta con el solucionario correspondiente (pendiente de incorporar).
