# Sesión 12 · Transferencia y verificación final

**Objetivo:** demostrar que puedes aplicar reglas en situaciones inéditas, no solo recordar las soluciones anteriores.

## Tareas nuevas (40 min)

**12.1. Scope.** Predice el error y corrige el código manteniendo una variable exterior llamada `message`:
```js
let message = 'outer';
function show() {
  console.log(message);
  const message = 'inner';
}
show();
```

**12.2. Referencias.** ¿Qué muestra y cómo lo reescribirías para que `base` se mantenga intacto?
```js
const base = { cart: { quantity: 1 } };
const copy = { ...base };
copy.cart.quantity = 9;
console.log(base.cart.quantity);
```

**12.3. Defaults.** Implementa `resolveOptions({ enabled, retries })` con valores por defecto `enabled=true`, `retries=2` solo si son `null` o `undefined`. Debe preservar `false` y `0`.

**12.4. Event Loop.** Predice el orden exacto:
```js
console.log('p');
Promise.resolve().then(() => {
  console.log('q');
  setTimeout(() => console.log('s'), 0);
});
queueMicrotask(() => console.log('r'));
console.log('t');
```

**12.5. Promesas.** Define `loadAll(ids, getter)` que inicie las llamadas a `getter(id)` de forma concurrente y devuelva los valores en el orden de entrada. ¿Qué pasa si uno rechaza?

**12.6. Set/Map.** Dado `[{sku:'a', price:10},{sku:'b',price:20},{sku:'a',price:15}]`, crea un array con un producto por `sku` conservando el **último** objeto de cada `sku`.

**12.7. `this`.** ¿Qué imprime? Justifica:
```js
const a = { points: 4, show() { return this.points; } };
const b = { points: 11 };
console.log(a.show.call(b));
```

**12.8. Microimplementación.** Implementa `async getPrices(ids, fetchPrice)` que devuelva `{ ok: [...], failed: [...] }`, siendo `ok` un array de `{id,price}` y `failed` un array de `{id,error}` con mensajes de error. Conserva el orden de entrada dentro de cada grupo; no abortes cuando falle un ID. Asume que `fetchPrice(id)` devuelve una promesa.

## Tres explicaciones orales (10 min)

**12.9.** Explica en menos de 75 segundos cómo saber si una promesa debe esperar a otra y qué diferencia existe entre `await` en un bucle y `Promise.all()`.

**12.10.** Explica en menos de 75 segundos la diferencia entre una copia superficial y una copia profunda. Incluye una advertencia sobre `const`.

**12.11.** Explica en menos de 75 segundos qué sucede al invocar una función `async` hasta su primer `await`.

## Validación final (10 min)

- Corrige con el solucionario correspondiente (pendiente de incorporar).
- Revisa el seguimiento de progreso de la plataforma y vuelve a resolver, con código diferente, los temas que sigan por debajo del 80 %.
- Marca como «dominados» solo los conceptos que puedas **justificar sin ayuda**.
- Antes de una prueba real, confirma el formato e instrucciones actuales de esa evaluación.
