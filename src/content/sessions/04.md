# Sesión 04 · Referencias, igualdad y copias

**Objetivo:** razonar la identidad de objetos, mutaciones, `spread`, `structuredClone` e inmutabilidad.

## Predice (25 min)

**4.1**
```js
const a = { id: 1 };
const b = { id: 1 };
console.log(a === b);
```

**4.2**
```js
const a = { id: 1 };
const b = a;
b.id = 6;
console.log(a.id);
```

**4.3**
```js
const a = { nested: { n: 1 } };
const b = { ...a };
b.nested.n = 5;
console.log(a.nested.n, a === b);
```

**4.4**
```js
const a = { nested: { n: 1 } };
const b = structuredClone(a);
b.nested.n = 5;
console.log(a.nested.n, b.nested.n);
```

**4.5**
```js
const a = [1, 2];
const b = [...a];
b.push(3);
console.log(a.length, b.length);
```

**4.6**
```js
const a = [{ id: 1 }];
const b = [...a];
b[0].id = 7;
console.log(a[0].id);
```

**4.7**
```js
const profile = Object.freeze({ name: 'Ana', prefs: { theme: 'light' } });
profile.prefs.theme = 'dark';
console.log(profile.prefs.theme);
```

## Programación (20 min)

**4.8.** Escribe `updateCity(user, city)` que devuelva un usuario nuevo con `address.city` modificada, **sin mutar** el usuario de entrada. Prueba con `{name:'Ana', address:{city:'Valencia',zip:46000}}`.

**4.9.** Demuestra con un ejemplo por qué `JSON.parse(JSON.stringify(obj))` no es un clonador general seguro para todo tipo de valores. Es suficiente usar `Date` o `undefined`.

## Cierre (10 min)

Dibuja flechas desde variables hacia objetos para los ejercicios 4.3 y 4.6. Correcciones: el solucionario correspondiente (pendiente de incorporar).
