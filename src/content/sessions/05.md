# Sesión 05 · Arrays, Set y Map

**Objetivo:** elegir operaciones sobre colecciones y evitar errores de mutación, comparación y deduplicación.

## Predice (20 min)

**5.1**
```js
const nums = [3, 1, 2];
const result = nums.sort((a, b) => a - b);
console.log(nums.join(','), result === nums);
```

**5.2**
```js
const vals = [1, 2, 3];
console.log(vals.map(x => x * 2).filter(x => x > 3));
```

**5.3**
```js
const data = ['a', 'b', 'a'];
console.log([...new Set(data)]);
```

**5.4**
```js
const a = { id: 1 };
console.log(new Set([a, { id: 1 }, a]).size);
```

**5.5**
```js
const map = new Map([['x', 1], ['y', 2], ['x', 3]]);
console.log(map.size, map.get('x'));
```

**5.6**
```js
const nums = [5, 10, 15];
console.log(nums.reduce((sum, n) => sum + n, 0));
```

## Construye (25 min)

**5.8.** Implementa `groupByCategory(items)` que produzca un objeto cuyas claves sean categorías y cuyos valores sean arrays de elementos. Entrada: `[{category:'book',id:1},{category:'game',id:2},{category:'book',id:3}]`.

**5.9.** Ordena precios de menor a mayor **sin modificar** el array original. Resuelve con `toSorted()` si tu entorno lo admite, y con otra alternativa si no.

**5.10.** Compara `find`, `findIndex` y `filter` con un array de usuarios: ¿qué devuelve cada método si ningún usuario cumple la condición?

## Cierre (10 min)
