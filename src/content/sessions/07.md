# Sesión 07 · Promesas y gestión de errores

**Objetivo:** dominar la propagación de valores y rechazos entre `then`, `catch`, `finally`, `throw` y `await`.

## Predice (30 min)

**7.1**
```js
Promise.resolve(5)
  .then(x => x + 1)
  .then(x => console.log(x));
```

**7.2**
```js
Promise.reject('oops')
  .then(() => console.log('A'))
  .catch(() => console.log('B'));
```

**7.3**
```js
Promise.reject('bad')
  .catch(() => 7)
  .then(value => console.log(value));
```

**7.4**
```js
Promise.resolve('ok')
  .finally(() => 'new')
  .then(value => console.log(value));
```

**7.5**
```js
Promise.resolve('ok')
  .finally(() => { throw new Error('cleanup'); })
  .then(() => console.log('yes'))
  .catch(err => console.log(err.message));
```

**7.6**
```js
async function test() {
  try {
    return await Promise.reject('bad');
  } catch {
    return 'recovered';
  }
}
test().then(console.log);
```

**7.7**
```js
async function test() {
  try {
    return Promise.reject('bad');
  } catch {
    return 'recovered';
  }
}
test().catch(err => console.log(err));
```

**7.8**
```js
Promise.resolve(2)
  .then(x => { throw new Error(String(x)); })
  .catch(err => Number(err.message) * 4)
  .then(console.log);
```

## Programación (15 min)

**7.9.** Implementa `safeJSON(text)` como función `async` que devuelva el objeto de `JSON.parse(text)` o `{ error: 'invalid-json' }` si el texto es inválido. No es necesario hacer una promesa artificial.

**7.10.** Implementa `withFallback(promise, fallback)` con `async/await`: devuelve el resultado de la promesa si se cumple y `fallback` si se rechaza.

## Cierre (10 min)

Explica por qué un `catch` que devuelve un valor transforma un rechazo en cumplimiento. Comprueba con el solucionario correspondiente (pendiente de incorporar).
