# Sesión 03 · Coerción y valores por defecto

**Objetivo:** distinguir `||`, `??`, `==`, `===`, truthy/falsy y los valores por defecto de la destructuración.

## Predice (25 min)

Para cada expresión, anota el valor **y su tipo** cuando resulte útil.

**3.1** `console.log(0 || 25);`

**3.2** `console.log(0 ?? 25);`

**3.3** `console.log('' ?? 'sin nombre');`

**3.4** `console.log(null || 'alternativo');`

**3.5** `console.log(Boolean([]), Boolean({}));`

**3.6** `console.log('8' + 2, '8' - 2);`

**3.7** `console.log(null == undefined, null === undefined);`

**3.8**
```js
const { timeout = 30, active = true, mode = 'auto' } = {
  timeout: null,
  active: false
};
console.log(timeout, active, mode);
```

**3.9**
```js
const data = { retries: undefined, port: 0 };
console.log(data.retries ?? 4, data.port || 8000);
```

**3.10**
```js
console.log([] == 0, [] === 0);
```

## Escribe (15 min)

**3.11.** Define `normalizeConfig(config)` que devuelva `{ retries, timeout, label }` usando estas reglas: `retries` = 3 si es `null`/`undefined`; `timeout` = 1000 si es `null`/`undefined`; `label` = `'anon'` si es una cadena vacía, `null` o `undefined`. Conserva `0` en `retries` y `timeout`.

**3.12.** Explica con un contraejemplo por qué `const { host = 'localhost' } = { host: null }` no produce `'localhost'` y corrígelo sin mutar el objeto original.

## Cierre (10 min)

Redacta una regla de una frase para cada operador y compárala con el solucionario correspondiente (pendiente de incorporar).
