# Sesión 09 · Depuración de código real

**Objetivo:** encontrar fallos, explicar su causa, escribir una corrección y definir una prueba que evitaría la regresión.

En cada caso: (1) explica el comportamiento defectuoso, (2) corrige el código, (3) escribe un `console.assert` o un caso de prueba. Cada ejercicio es independiente.

## Ocho incidencias (45 min)

**9.1. Los productos no están disponibles cuando se imprimen.**
```js
async function getPrice(id) { return id * 7; }
async function listPrices(ids) {
  const prices = ids.map(async id => getPrice(id));
  return prices;
}
listPrices([1, 2]).then(console.log);
```
Esperado: `[7, 14]`.

**9.2. Una actualización modifica el perfil original.**
```js
function setTheme(account, theme) {
  const copy = { ...account };
  copy.preferences.theme = theme;
  return copy;
}
```
Esperado: cuenta original intacta; objeto de retorno con nuevo tema.

**9.3. El filtrado convierte en activos todos los usuarios.**
```js
const active = users.filter(user => user.active = true);
```
Esperado: conservar solo los usuarios que ya tenían `active === true`.

**9.4. La función cambia los datos originales.**
```js
function rank(scores) {
  return scores.sort((a, b) => b - a);
}
```
Esperado: resultado descendente sin modificar `scores`.

**9.5. El array contiene `undefined` en lugar de objetos.**
```js
const cards = [1, 2].map(id => { id: id });
```
Esperado: `[{id:1},{id:2}]`.

**9.6. El precio cero se convierte en un precio predeterminado.**
```js
function displayPrice(price) {
  return price || 100;
}
```
Esperado: conservar `0` y sustituir solo `null` o `undefined`.

**9.7. Una API que responde HTTP 500 parece haberse completado correctamente.**
```js
async function getItems(url) {
  const response = await fetch(url);
  return response.json();
}
```
Esperado: lanzar error para respuestas HTTP no satisfactorias.

**9.8. La recuperación local de errores no funciona.**
```js
async function save() {
  try {
    return Promise.reject(new Error('offline'));
  } catch {
    return { saved: false };
  }
}
```
Esperado: devolver `{ saved: false }` en el rechazo.

## Revisión (15 min)

Antes de mirar el solucionario correspondiente (pendiente de incorporar), clasifica cada bug: asincronía, referencia, coerción, control de flujo, mutación, error HTTP o sintaxis.
