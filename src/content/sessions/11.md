# Sesión 11 · Simulacro de 20 preguntas

**Duración sugerida:** 35 minutos para las preguntas y 15 para corrección. Sin ejecutar el código, sin documentación, sin soluciones y sin IA durante el simulacro. Una opción correcta por pregunta. Código independiente por ejercicio. Los ejemplos con `setTimeout` se ejecutan en un entorno estándar de JavaScript con event loop.

**11.1.** ¿Qué muestra?
```js
let x = 3;
{ const x = 4; }
console.log(x);
```
A) `4` · B) `3` · C) `undefined` · D) `ReferenceError`

**11.2.** ¿Qué muestra?
```js
function check() { return typeof unknownVariable; }
console.log(check());
```
A) `null` · B) `"object"` · C) `"undefined"` · D) `ReferenceError`

**11.3.** ¿Qué muestra?
```js
const a = { nested: { n: 1 } };
const b = { ...a };
b.nested = { n: 2 };
console.log(a.nested.n);
```
A) `1` · B) `2` · C) `undefined` · D) `TypeError`

**11.4.** ¿Qué muestra?
```js
const s = new Set([0, -0, NaN, NaN]);
console.log(s.size);
```
A) `1` · B) `2` · C) `3` · D) `4`

**11.5.** ¿Qué muestra?
```js

```
A) `6` · B) `13` · C) `16` · D) `12310`

**11.6.** ¿Qué muestra?
```js
console.log('5' * 2 + 1);
```
A) `11` · B) `"521"` · C) `10` · D) `NaN`

**11.7.** ¿Qué muestra?
```js
const name = '';
console.log(name ?? 'guest');
```
A) `"guest"` · B) `null` · C) `undefined` · D) `""` (cadena vacía)

**11.8.** ¿Qué muestra?
```js
const { size = 7 } = { size: null };
console.log(size);
```
A) `7` · B) `undefined` · C) `null` · D) `0`

**11.9.** ¿Qué muestra?
```js
const next = (() => {
  let x = 1;
  return () => ++x;
})();
console.log(next(), next());
```
A) `1 2` · B) `2 3` · C) `2 2` · D) `3 3`

**11.10.** ¿Qué muestra?
```js
const a = { n: 2, read() { return this.n; } };
const b = { n: 8, read: a.read };
console.log(b.read());
```
A) `2` · B) `undefined` · C) `TypeError` · D) `8`

**11.11.** ¿Qué muestra?
```js
function Box() {
  this.n = 4;
  this.get = () => this.n;
}
const box = new Box();
console.log(box.get.bind({ n: 9 })());
```
A) `9` · B) `4` · C) `undefined` · D) `TypeError`

**11.12.** ¿Qué orden aparece?
```js
console.log('a');
queueMicrotask(() => console.log('b'));
console.log('c');
```
A) `a, b, c` · B) `b, a, c` · C) `a, c, b` · D) `c, a, b`

**11.13.** ¿Qué muestra?
```js
Promise.resolve(3)
  .then(() => { throw new Error('x'); })
  .catch(() => 8)
  .then(console.log);
```
A) `8` · B) `3` · C) `"x"` · D) Nada, rechazo no manejado

**11.14.** ¿Qué muestra?
```js
Promise.resolve(4)
  .finally(() => 10)
  .then(console.log);
```
A) `10` · B) `undefined` · C) `4` · D) Nada, error

**11.15.** ¿Qué muestra al terminar?
```js
const slow = new Promise(resolve => setTimeout(() => resolve('S'), 20));
const fast = Promise.resolve('F');
Promise.all([slow, fast]).then(values => console.log(values.join(',')));
```
A) `F,S` · B) `S,F` · C) `S` · D) `F`

**11.16.** ¿Qué muestra?
```js
const a = [2, 4]
  .map(n => { const half = n / 2; })
  .filter(Boolean);
console.log(a);
```
A) `[1, 2]` · B) `[undefined, undefined]` · C) `[2, 4]` · D) `[]`

**11.17.** ¿Qué muestra?

**11.18.** ¿Qué muestra?
```js
const o = Object.create({ x: 1 });
o.y = 2;

```

**11.19.** ¿Qué orden aparece?
```js
async function f() {
  console.log(1);
  await 1;
  console.log(3);
}
f();
console.log(2);
```
A) `2, 1, 3` · B) `1, 3, 2` · C) `3, 1, 2` · D) `1, 2, 3`
