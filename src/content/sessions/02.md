# Sesión 02 · Closures y `this`

**Objetivo:** distinguir el estado retenido por un closure del valor de `this` en funciones tradicionales y flecha.

## Antes de empezar (10 min)

Define de memoria «closure» y predice cuándo una función conserva una variable exterior. Recuerda que una flecha no tiene su propio binding de `this`.

## Predicción (20 min)

**2.1**
```js
function multiplier(base) {
  return n => n * base;
}
const double = multiplier(2);
const triple = multiplier(3);
console.log(double(4), triple(4));
```

**2.2**
```js
let value = 1;
const read = () => value;
value = 7;
console.log(read());
```

**2.3**
```js
function makeAdder() {
  let total = 0;
  return amount => (total += amount);
}
const a = makeAdder();
const b = makeAdder();
console.log(a(2), a(3), b(4));
```

**2.4**
```js
const box = {
  value: 4,
  get() { return this.value; }
};
const other = { value: 9, get: box.get };
console.log(other.get());
```

**2.5**
```js
function Container() {
  this.value = 4;
  this.get = () => this.value;
}
const c = new Container();
console.log(c.get.call({ value: 9 }));
```

**2.6**
```js
function make() {
  let count = 0;
  return {
    next: () => ++count,
    peek: () => count
  };
}
const x = make();
console.log(x.next(), x.peek(), x.next());
```

**2.8.** Implementa `once(fn)` para que la función pasada se ejecute solo en la primera llamada. En siguientes llamadas, debe devolver el primer resultado sin volver a invocarla. Prueba una función que incremente un contador.
